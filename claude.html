Step by Step

The Parallel Workflow

A proven approach to maximizing throughput while maintaining code quality and avoiding conflicts.

1

Plan & Decompose

Break your project into independent tasks that can run in parallel without stepping on each other. Create context documents for each task.

💡 Use Claude Cowork to auto-generate task markdown files with vision docs and style guides included.
2

Isolate Environments

Set up git worktrees or separate directories for each agent. This prevents file conflicts and allows parallel writes to the same codebase.

💡 Each worktree gets its own working directory but shares the same git history—perfect for feature branches.
3

Spawn Agents

Launch Claude instances in each environment. Assign specific roles or tasks to each agent. Consider using "aggressive" mode for trusted automated tasks.

💡 Run claude --dangerously-skip-permissions for auto-accept mode on trusted tasks. Use in containers for safety!
4

Monitor & Rotate

Toggle between agents while they process. Queue up next prompts while waiting on responses. Use tiled views to monitor all agents simultaneously.

💡 Claude Code natively supports synthesizing outputs from parallel agents—let it merge context for you.
5

Review & Merge

Once all agents complete, review changes in each branch. Resolve any conflicts, run tests, and merge back to main. Clean up worktrees when done.

💡 Consider integrating Gemini or another tool for visual QA testing before final merge.
Best Practices

Pro Tips

Hard-won wisdom from power users running parallel Claude workflows.

💾

Always Backup First

Before granting any agent folder access, back up important files. Agents can modify or delete files if misinterpreted—protect your work.

🎯

Keep Projects Distinct

Only parallelize across separate projects or truly independent features. Overlapping code changes create merge nightmares.

📋

Assign Specific Roles

Give each agent a clear, focused responsibility. "You handle tests, you handle API, you handle UI" prevents duplicate work.

🔄

Rotate Strategically

Queue up your next prompt while waiting on a response. By the time you finish typing, the other agent is likely done.

📁

Use Context Docs

Create CONTEXT.md or CLAUDE.md files in each workspace with project vision, style guides, and constraints for consistent outputs.

🐳

Container for YOLO Mode

Running --dangerously-skip-permissions? Use Docker containers without network access to limit blast radius if something goes wrong.

🧹

Clean Up Worktrees

Remove worktrees after merging with git worktree remove. They persist on disk and can clutter your system.

🔀

Merge Frequently

Pull and merge updates from main regularly. This prevents your worktree from drifting too far and creating massive conflicts.

Step 5 of 6

Describe Your Task

Now the fun part! Tell Claude what you want accomplished. Be specific about the outcome you want.

Example Prompt — Expense Report
Look at all the receipt images in this folder. Extract the vendor name, date, amount, and category from each receipt. Then create an Excel spreadsheet with: - A row for each expense - Columns for Date, Vendor, Amount, Category - A total row at the bottom with SUM formula - Sort by date, newest first
Example Prompt — File Organization
Organize all files in this folder by: 1. Creating subfolders for each file type (Documents, Images, Spreadsheets, Other) 2. Moving files into appropriate folders 3. Renaming each file with today's date prefix (YYYY-MM-DD) 4. Creating a summary.txt with a list of all organized files
Example Prompt — Research Synthesis
Read all the PDF documents in this folder (they're research papers about renewable energy). Create a Word document that summarizes: - The main findings from each paper - Common themes across all papers - Conflicting viewpoints if any - A bibliography section at the end
✨
Pro Tip: The more specific you are, the better the results. Include the exact output format you want, file names, and any constraints. Claude will make a plan and show you before executing.
